# Android 开发学习规划

## 学习目标

通过一条以 Android 实际开发流程为主线的学习路线，逐步掌握 Android Studio、Android 平台基础、Jetpack Compose、应用数据与业务开发、C++ / Native 开发，以及真机与设备能力。

最终目标不是“独立完成某个商业级 App”，而是通过连续、可运行的实践，把 Android 开发中最主要的知识体系串起来，并能够在真机上运行和验证所学内容。

---

## 总体原则

- 使用 **Android Studio** 作为开发 IDE。
- Android 主体语言使用 **Kotlin**。
- Native 层使用 **C++**。
- Kotlin 语法不单独设置学习阶段，默认已有基础；遇到 Android 常用但不熟悉的语法或特性时再补。
- UI 开发以 **Jetpack Compose** 为主，不把传统 XML View 系统纳入主线学习。
- 前期统一使用 **Android 模拟器**。
- 真机部署、设备差异和硬件能力放到最后阶段。
- 每个阶段都应有可运行、可观察的实践结果，而不是只阅读资料。
- 学习重点是理解 Android 的开发模型和平台特性，而不是机械覆盖整个 Android SDK。

---

# 阶段 1：开发环境与 Android 项目入门

## 目标

1. 能够独立创建一个 Android 项目。
2. 能够理解项目的大体结构。
3. 能够完成项目的构建与运行。
4. 能够熟练使用 Android 模拟器。
5. 能够进行最基本的调试和问题定位。
6. 能够修改项目内容，并确认修改结果正确生效。
7. 对 Gradle 在 Android 项目中的作用形成基本认识。

## 阶段完成标准

能够从空的 Android Studio 开始，创建项目、修改内容、构建并运行到模拟器；遇到简单问题时，知道应该从哪里观察和排查。

---

# 阶段 2：Android 平台基础

## 目标

1. 理解 Android 应用的基本组成与运行方式。
2. 理解 Activity、应用进程和任务之间的大致关系。
3. 理解 Android 的生命周期模型。
4. 理解应用在前台、后台以及被系统回收时的行为。
5. 理解 Android 的权限与安全隔离机制。
6. 理解 Android 的文件系统与应用存储环境。
7. 理解 Android 的后台任务与后台运行限制。
8. 理解应用与 Android 系统、其他应用交互的基本机制。
9. 理解不同 Android 版本和设备环境可能带来的基本差异。
10. 能够判断一个需求主要涉及哪类 Android 平台能力。

## 阶段完成标准

脑中形成一张基本的 Android 平台地图。面对一个需求时，能够判断它主要涉及生命周期、后台运行、权限、存储、系统交互等哪一类平台能力。

## 范围边界

这一阶段不展开摄像头、蓝牙、定位、传感器等具体设备能力，它们统一放到最后的真机阶段。

---

# 阶段 3：Android 界面开发

## 目标

1. 能够使用 Jetpack Compose 构建常见应用界面。
2. 理解声明式 UI 的基本思路。
3. 能够管理界面状态，并让界面随状态变化正确更新。
4. 能够处理用户输入和各种界面交互。
5. 能够组织多个页面，并完成页面之间的导航。
6. 能够构建具有一定层次和复用性的界面结构。
7. 能够适配常见的屏幕尺寸、方向和系统界面变化。
8. 能够处理加载、空状态、错误状态等常见 UI 状态。
9. 能够让界面与 Android 平台生命周期正确配合。
10. 能够完成一个多页面、有完整交互流程的小型 App 界面。

## 阶段完成标准

给定一个简单 App 的界面需求，可以把页面、状态、交互和导航完整做出来，并保持比较清楚的界面结构。

## 范围边界

主线只学习 **Jetpack Compose**。传统 XML View 系统不进入当前学习计划；以后如果遇到旧项目或兼容需求，再单独补充。

---

# 阶段 4：应用数据与业务开发

## 目标

1. 理解 Android 应用中的数据应该怎样组织和流动。
2. 能够保存并读取应用的本地数据。
3. 能够使用本地数据库管理结构化数据。
4. 能够从网络获取数据，并处理网络请求结果。
5. 能够协调本地数据与远程数据。
6. 理解异步任务在应用业务逻辑中的基本处理方式。
7. 能够把界面、业务逻辑和数据访问适当地分开。
8. 能够处理加载、失败、重试、数据为空等常见业务状态。
9. 能够让应用在关闭、重新启动或部分状态变化后保持合理的数据状态。
10. 能够完成一个真正以数据驱动的小型 Android App。

## 阶段完成标准

能够做出一个不再只是“界面 Demo”的应用：数据可以保存、查询、通过网络获取，并且 UI、业务逻辑和数据之间有比较清楚的关系。

---

# 阶段 5：C++ / Android Native 开发

## 目标

1. 理解 C++ 在 Android 应用中的定位与适用场景。
2. 能够在 Android 项目中建立并维护 Native 模块。
3. 理解 Kotlin 与 C++ 之间的调用边界和数据交互方式。
4. 能够完成常见数据在 Kotlin 与 C++ 之间的传递。
5. 理解 Native 代码的构建、编译和链接流程。
6. 能够集成实际的第三方 C++ 库，例如 Eigen。
7. 使用 C++ 实现一个具有明显 Native 特点的计算密集型模块。
8. 能够从 Kotlin 层调用该模块，并把结果返回给 Android 应用使用。
9. 能够调试 Native 代码，并定位基础的崩溃、构建和链接问题。
10. 能够判断一个功能是否值得放到 C++ 层实现。

## 阶段完成标准

在已有 Android App 中，集成至少一个真实的 C++ 第三方库，并完成一个计算密集型功能模块，从 Kotlin 调用到 C++、执行计算、返回结果，再交给 Android 应用使用。

## 范围边界

这一阶段不是重新系统学习 C++。默认已有 C++ 基础，重点是学习 **C++ 如何进入 Android 工程并承担合适的功能**。

---

# 阶段 6：真机运行与设备能力

## 目标

1. 能够把前面阶段的 Android 项目部署到真实设备上。
2. 理解模拟器与真机环境之间的主要差异。
3. 能够在真机上进行基本调试和问题定位。
4. 理解真实设备上的权限、系统限制和运行环境。
5. 以 **蓝牙** 作为具体例子，学习 Android 如何访问设备硬件能力。
6. 理解蓝牙功能涉及的权限、设备发现、连接和数据交互这一整类问题。
7. 能够把一个简单蓝牙功能接入已有 Android App。
8. 观察并处理真机上才比较容易遇到的问题。
9. 了解正式构建、签名和安装包在真实设备上的作用。
10. 把前面学到的平台、UI、数据和 Native 内容放到真机环境中重新理解一遍。

## 阶段完成标准

通过真机和蓝牙这个具体例子，理解 Android 应用从模拟环境进入真实设备后，会增加哪些平台约束、权限问题和硬件交互问题。

---

# 学习路线总览

```text
阶段 1
开发环境与 Android 项目入门
        ↓
阶段 2
Android 平台基础
        ↓
阶段 3
Android 界面开发（Jetpack Compose）
        ↓
阶段 4
应用数据与业务开发
        ↓
阶段 5
C++ / Android Native 开发
        ↓
阶段 6
真机运行与设备能力（蓝牙）
```

整条路线的变化可以概括为：

**能运行 Android 项目 → 理解 Android 平台 → 能构建完整 UI → 能处理真实应用数据 → 能加入 C++ Native 模块 → 能在真实设备上验证并使用硬件能力。**
